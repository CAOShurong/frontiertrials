One traceable lifecycle

From a browser response
to a defensible result.

Each transition produces an artifact that another person can inspect, rerun, or challenge.

  1. 01

    Design

    Write tasks, rubrics, metadata, and an interpretation boundary before seeing results.

  2. 02

    Capture

    Save exact Markdown outputs and their SHA-256 digests. No provider automation is required.

  3. 03

    Freeze

    Generate deterministic aliases, all-pairs comparisons, balanced sides, and rater allocations.

  4. 04

    Review offline

    Share self-contained HTML packets that collect pairwise choices, scores, confidence, and rationale.

  5. 05

    Diagnose

    Estimate relative strength and uncertainty, then inspect agreement, task, side, and verbosity effects.

  6. 06

    Reveal & seal

    Reveal identities only after ratings, publish a portable report, and seal the evidence tree.

Bias-aware

Side balance, verbosity preference, reviewer agreement, and task slices expose reasons to distrust a rank.

Honest interpretation

A ranking is evidence about
this trial—nothing more.

It does not prove general intelligence, factual correctness, or future product behavior.

Web products may change routing, tools, context limits, and hidden instructions without notice.

Small task sets and correlated reviewers can make intervals look more certain than reality.

Private content stays local only if you keep the trial local; publication is an explicit choice.

Zero runtime dependencies

Start with one command.

Python 3.11+ · MIT licensed · works offline after installation

$ python -m pip install frontiertrials
$ frontiertrials demo my-trial
$ frontiertrials audit --trial my-trial
$ frontiertrials verify --trial my-trial
