# Reasoning and result

This work proposes an edge fault detector that adapts predictive confidence under thermal drift. The method distinguishes classification accuracy from calibration error so that correct labels are not mistaken for reliable probabilities. We define a temperature-aware recalibration stage and an evaluation protocol spanning controlled thermal conditions. Experiments have not yet been completed; therefore, no performance improvement is claimed. Future work will measure accuracy, calibration, latency, and energy with repeated trials.
