# Roadmap

## Near term

- Longitudinal trials that compare capture waves without merging changing interfaces.
- Optional incomplete block designs for larger candidate sets.
- Rater-specific packet splitting by expertise and workload.
- Sensitivity analysis for rubric weights and confidence thresholds.
- Accessibility review for keyboard-only packet completion.
- Signed capture and seal attestations.

## Later, if evidence supports the need

- Opt-in import adapters for evaluation frameworks that export exact responses.
- Multiple independent response draws per task/candidate.
- Ordinal mixed models behind an optional scientific dependency extra.
- Private static-site bundles with encrypted reveal material.

## Non-goals

- Automating consumer web apps.
- Evading rate limits or provider terms.
- Using a hidden model as the default judge.
- Claiming a small task set measures general intelligence.
- Publishing a live global leaderboard.
- Automatically deleting identity cues from captured responses.
