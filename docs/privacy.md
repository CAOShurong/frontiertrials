# Privacy and safe sharing

## Private prompts

Real tasks may contain unpublished ideas, source code, participant information, internal documents,
or personal data. Local-first storage prevents automatic upload by FrontierTrials, but copied
content has already been submitted to each evaluated provider under that provider's terms.

Do not use consumer AI products for material you are not authorized to disclose.

## Judging packets

Packets contain prompts, contexts, references, and responses. They are self-contained precisely so
they can work offline; that also means anyone with the file can read the content. Use encrypted or
access-controlled transfer when necessary.

## Reports

The public report embeds analysis, candidate identities, protocol metadata, and audit details.
Review it before publication. The demo is safe to publish because every record is fictional.

## Raters

Use pseudonyms and store only expertise needed to interpret the panel. Consent and institutional
rules may apply when evaluation becomes human-subject research or employee performance assessment.
FrontierTrials does not determine that status.

## Provider terms

The tool does not automate web collection. Manual use can still be restricted by account,
organizational, geographic, or data-handling rules. Review the current terms that apply to each
surface.
